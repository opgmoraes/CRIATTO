📍 PASSO 1: COPIAR ARQUIVOS PARA SEU PROJETO

1. Extrair este ZIP em uma pasta temporária
2. Copiar os arquivos para seu projeto CRIATTO:

   Windows (PowerShell):
   xcopy "src\components\*.tsx" "seu_projeto\src\components\" /Y
   xcopy "app\api\*.ts" "seu_projeto\app\api\" /Y

   Linux/Mac (Terminal):
   cp -r src/components/*.tsx seu_projeto/src/components/
   cp -r app/api/*/route.ts seu_projeto/app/api/

   OU MANUALMENTE:
   - Copiar 5 arquivos .tsx da pasta src/components/ → seu_projeto/src/components/
   - Copiar 2 arquivos de API routes da pasta app/api/ → seu_projeto/app/api/

📍 PASSO 2: ADICIONAR AOS SEUS COMPONENTES

No seu componente principal (ex: app/page.tsx ou CarouselEditor.tsx):

```tsx
import { AdvancedGenerationModal } from '@/components/advanced-generation-modal';
import { EditSlidesModal } from '@/components/edit-slides-modal';      // NOVO
import { LogoUploadModal } from '@/components/logo-upload-modal';      // NOVO
```

Adicione os estados:

```tsx
const [showEditModal, setShowEditModal] = useState(false);             // NOVO
const [showLogoModal, setShowLogoModal] = useState(false);             // NOVO
const [logo, setLogo] = useState(null);                               // NOVO
const [isRegenerating, setIsRegenerating] = useState(false);          // NOVO
```

Adicione os modais no JSX:

```tsx
<EditSlidesModal
  isOpen={showEditModal}
  onClose={() => setShowEditModal(false)}
  slides={slides}
  onSave={handleSaveSlides}
  onRegenerateSingle={handleRegenerateSingle}
  isRegenerating={isRegenerating}
/>

<LogoUploadModal
  isOpen={showLogoModal}
  onClose={() => setShowLogoModal(false)}
  onLogoSelect={handleLogoSelect}
  currentLogo={logo?.url}
/>
```

3. Clicar em "✏️ Editar Slides"
4. Testar:
   - Editar headline/body
   - Trocar imagens
   - Regenerar um slide (🔄)
   - Reordenar com drag & drop
5. Clicar em "🎨 Adicionar Logo"
6. Fazer upload de uma imagem
7. Conferir logo em todos os slides

❓ TROUBLESHOOTING

"Modal não aparece"
→ Verifique se isOpen={true} está sendo passado

"Regeneração não funciona"
→ Verifique se /api/regenerate-slide/route.ts foi copiada corretamente

"Logo não aparece nos slides"
→ Verifique se o código de renderização inclui a logo (veja exemplo)

"Estilos estranhos"
→ Certifique-se de que Tailwind CSS está configurado
